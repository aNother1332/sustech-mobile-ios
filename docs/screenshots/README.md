# 界面截图来源

- 应用：SUSTechMobile 0.2.0。
- 截图源码提交：`d0038c5`。
- 云端运行：https://github.com/aNother1332/sustech-mobile-ios/actions/runs/40112664828
- 环境：Xcode 26.0，GitHub Actions macOS runner，iPhone 与 iPad 模拟器。
- 共 18 张原始 PNG：每种设备各 9 张，包含今天、课表、考试、成绩、BB、办事、我的、原生登录及系统桌面。
- 数据：演示模式虚构课程、任务与考试；成绩显示尚未同步状态；登录表单为空。未使用真实校园账号或 Apple 账号。
- 页面切换通过仅在 Debug 构建中生效的启动参数完成，没有为截图伪造真实服务响应。
- 截图脚本：[`scripts/simulator_smoke.py`](../../scripts/simulator_smoke.py)。

这些截图用于展示当前界面，不代表真实学校接口已经完成验收。桌面截图中的系统界面和壁纸属于模拟器环境。
