# SUSTechMobile 0.8.0 / build 12

- 修复底栏在栏目切换时被 keyed 页面连同重建，导致选中态动画消失的问题；底栏改为稳定身份，点击与拖动释放均使用弹簧，内容页淡入淡出。iOS 26+ 使用交互式原生玻璃底面及染色玻璃选中态；低版本继续半透明材质。减少透明度设置仍优先使用实色，“我的”显示实际材质选择。
- 首页进入、回到前台、下拉刷新自动读取校园卡余额。读数失败区分需要连接和暂未刷新，保留已有读数；请求去重并阻止换账号后的旧数据写回。
- 首页“日程与服务”改为直接显示近七天待办：待交作业、考试、个人事项及已同步预约；支持进入事项设置提醒。无待办显示简短空状态。
- 移除图书馆与排课的 App 功能页、入口、深链和截图场景；日程不再读取图书馆借阅。历史版本与纯协议解析保留。
- 页头与个人信息卡融入学校官网原始校徽/中英文校名组合图，以低透明度模板渲染，保留文字对比度。图源：https://www.sustech.edu.cn/static/images/sustech-logo-cn.png 。仅用于非官方校园工具视觉参考，不代表学校授权或认可。
- 体育授权简化为复制专用授权链接并打开企业微信、系统粘贴连接、明确连接状态；已连接可复制本机密钥，剪贴板仅本机且 60 秒失效。导入密钥后先通过学校接口验证，才能保存并展示场馆。无扫码要求，不实现抢场。`wxwork://` 仅唤起企业微信，授权链接仍需用户粘贴打开。
- 充值页面增加复制学校链接并唤起企业微信；回到 App 自动查余额与账单。原生验证页增加本人主动粘贴学校授权回调和自定义金额本机草稿（如 3、3.25 元）。金额不是订单，不会发出充值 POST；自定义金额服务端支持、支付跳转及单笔到账查询仍未证实，原生正式下单继续关闭。

## 仍需设备核对

底栏玻璃与动画手感、减少透明度/动态效果、真实校园卡余额、企业微信唤起/复制回调、真实体育预约登录态及学校自定义充值金额。开发期间不执行真实预约、充值或付款。截图和演示账号不作为真实业务验收。
