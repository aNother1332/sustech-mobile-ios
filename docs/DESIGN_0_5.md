System blue/purple distinguish academic searches and reservations. System warning/red remain
semantic error/urgent states, always accompanied by labels/symbols. Light cyan is not used as
body text on white. Official dark green uses a brighter derived foreground in dark mode;
background identity uses the exact published RGB. Native semantic surfaces keep contrast.

Applied apple-design: system typography and Dynamic Type, familiar navigation/sheets,
responsive native press feedback, critical-damping spring (0.25 s response) only on press,
Reduce Motion disables scaling, native materials/navigation instead of custom gesture layers.
Timetable defaults to a dense weekly grid with span-height course blocks and switches to a
readable list at accessibility sizes. iPad uses adaptive service columns and split navigation.

Primary data uses weight/size and contrast. Supporting data uses system secondary text.
Procedural explanations use disclosure controls. Colour never replaces status wording.
No animation gates input, no looping decorative motion or moving full-screen backgrounds.

Validation: inspect iPhone/iPad light/dark, large text, code, calendar, faculty, services,
card, printing and reservations simulator captures; real device touch/VoiceOver check remains.
