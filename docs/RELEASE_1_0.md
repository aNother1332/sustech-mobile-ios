# SUSTechMobile 1.0.0 / build 17

本版只对 0.11.0 做三项小范围修正，并将版本号定为 1.0.0。

- “办事”入口顺序调整为：校园打印／预约中心 → 请假／学生活动 → 我的日程／教学日历。
- 首页“校园卡余额”整张卡片可点击进入校园卡；“待办”整张卡片可点击进入现有的“我的日程”。保留原来的卡片外观与数据读取方式。
- 修复较早周次课表显示不全：网格和列表统一使用教务返回的周次、星期及节次，不再经过公共校历的放假/调休过滤而隐藏或移位课程。第四、第五周跨国庆时，教务明确返回的课程仍完整显示。未知周次仍单列，当前周回退数据不冒充全学期。校历和日历功能保持原有规则。

没有新增学校接口、真实账号测试或学校写操作；测试仅使用虚构课程和界面样例。原有打印、预约、请假等功能的使用范围及验证边界沿用 0.11.0。

构建、测试和安装包核验在发布时补充。
