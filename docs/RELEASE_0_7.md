# SUSTechMobile 0.7.0 / build 11

## 用户确认的设计与本轮实现

- 根据用户提供的学校论坛截图，统一橙白设计语言：橙色渐变、白色内容面、线性 SF Symbols、等大功能入口、业务分组、短标签。默认使用 SwiftUI 系统字体（SF / 系统中文字体），无内置第三方字体。
- 首页、学习、办事、我的、预约中心、校园卡/打印/图书馆目录重排；其他业务内容沿用功能，统一共享卡片、强调色与操作样式。设计原型保存在独立 `design/orange-white-prototype` 分支，未将 HTML 当成正式 App。
- 学习顶部按实际已同步数据显示今日课程、最近考试、最近待交作业；缺失项隐藏。只计入未来且明确 pending/draft 的作业，已提交、豁免、未知状态与折叠课程排除。完整课表/考试/成绩/BB 用默认折叠的自定义面板呈现。
- 我的顶部读取教务 `/user/me` 的明确个人资料字段：姓名、学号、专业、院系、书院。缺失不推测，不把 `id/yhdm` 当学号。仅有登录账号时明确标为账号。资料与账号关联，进入/下拉可刷新，退出和换号清除；演示资料明确为示例。
- 底栏使用悬浮胶囊、系统图标与文字。拖动时选中背景随手势移动，释放提交栏目并弹簧归位；减少动态效果时去掉弹簧。iOS 26 使用原生 `glassEffect`，iOS 17–25 使用 material 回退，减少透明度时使用实色。
- 应用内操作确认与学校连接选择使用自定义表面，保留一次提交、角色与写入互斥；系统定位、文件和分享交互保留系统提供的 UI。选择学期等业务表单控件仍为系统控件。

## 校园巴士

- 单一地图页面，取消旧“站点与到站”标签、暂停服务车辆开关和常驻说明。数据来源与对齐设置在自定义信息面板中保留。
- 前台定位并展示本人位置；拖动地图停止相机跟随，定位按钮恢复。定位失败可选站，按所选位置计算两方向各自最近的真实平台，不显示步行距离。离页/后台停止定位。
- 左上角分方向展示最近平台及 ETA。环线标为 ↻ 1路内环 / ↺ 2路外环；k1/k2 区间继续车辆图标和平台方向。
- 点击车辆或平台使用自定义小浮卡；车的下一站 ETA 必须精确匹配 trip_id + route_direction_id，缺失显示“—”。站点按线路/方向取最早可用预测；实时分钟和计划时刻分别表达。过期车辆仍为灰色，不能把上次位置当新定位。
- 地图继续绘制接口完整 geometry 点序列，不使用设计原型的几何示意，不把站点用直线相连。圆角端点/连接；保留 WGS-84 → GCJ-02 展示层校准，源坐标不改写。
- 下方自定义可拖动时刻表抽屉，默认收起，按当天 `/schedules` 分线路/方向显示和筛选，优先定位当前时间附近。颜色基于首站计划发车：过去超过 20 分钟灰、0–20 分钟橙、未来墨绿，不声称已真实发车。
- 公共接口继续每 10 秒前台刷新；模式/账号变化清理局部状态，防止演示和真实数据混合。

## 验证与边界

新增测试覆盖个人资料字段、未知 ID 不当学号、提交状态与截止日期筛选、考试实际起始时间、20 分钟边界与坏时刻、车辆预测精确归属。云端执行核心测试、打包检查、模拟器与 iPhoneOS arm64 构建及选定 UI 截图。

未用真实校园账号执行登录/预约/打印/支付。学校资料的实际返回字段、运行中车辆 trip_id/下一站字段稳定性、定位/地图校准、底栏手势手感仍需用户设备核对。学校不返回专业等字段时保持缺失，不能宣称已读取所有学生完整资料。扩展签名/App Groups 与此前版本一样需要单独实机验证。
