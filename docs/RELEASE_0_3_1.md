# 0.3.1 · 校园卡充值入口

版本 0.3.1，构建 6。基于 0.3.0 增加原生充值渠道页，App 名称仍为 SUSTechMobile。

## 使用

1. 在校园卡页面选择“校园卡充值”。
2. 支付宝：点击“前往支付宝充值”，经提供的支付宝链接进入小程序；如不能唤起，使用分享链接到支付宝打开。
3. 微信 / 企业微信：分享或复制学校充值网址，在学校支持的客户端中打开并授权。
4. 在支付平台核对学校、学号、姓名、金额和实际收款方，由本人确认付款。
5. 返回充值页，点击“刷新余额与近期账单”。登录失效时需先重新连接校园卡服务。

## 实现范围

渠道页、操作反馈与账单查询为 SwiftUI 原生界面。金额输入、平台身份授权及支付由外部平台完成。本版未实现原生充值下单，也未验证完整充值闭环。学校充值的微信身份与 CAS 登录不同。网址中的 `pay_money=1` 未证实是金额预填参数，因而不添加无效的原生金额输入。

支付宝链接可只读解析到预选南方科技大学的充值小程序；其运营方、收款商户和实际到账须在真实平台核对。分享菜单是否提供微信/企业微信/支付宝取决于设备及应用安装状态。返回 App、打开网址成功或余额变化不会被标记为本次充值成功。未查明原订单状态时不要重复付款。

本地仓库一致性与 41 个 Swift 语法树检查通过；云端 51 项 Swift 测试、7 项打包测试、iPhone/iPad 模拟器及 arm64 真机编译通过，38 张截图完成，已查看两张新增充值页截图。成功构建：[40161165150](https://github.com/aNother1332/sustech-mobile-ios/actions/runs/40161165150)。包内版本与校验值已核对，详见 BUILD_VALIDATION.md。未使用真实校园账号、未创建订单或付款。

真机需验证：支付宝已装/未装、学校与学号显示、企业微信授权、取消付款、返回未支付、延迟到账、余额查询失效、iPad 分享菜单与横屏。只有用户实际核对付款及校园卡到账后，才能确认该渠道可用。
