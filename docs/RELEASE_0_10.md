# SUSTechMobile 0.10.0 / build 14

本版按真实账号只读接口结果修复校园会话和业务数据；模拟器只用于布局验证，不用演示数据代替真实业务验收。

- 所有在用学校 Cookie 原生客户端共用自动续接：确认业务会话失效后复用 CAS 交换一次，查询最多重读一次；网络/限流/权限错误不反复提交密码。写入、删除、取消、上传、付款不自动重发。CAS 也过期时，遵循用户原先选择的本机自动登录策略。
- 修复旧客户端把未变化的其他业务 Cookie 写回共享存储的问题，避免旧快照覆盖刚更新的校园卡等会话。
- NCES 的四维指标兼容原站小数字符串，总评分固定两位小数。
- IC 连续楼层查询加入 1.1 秒间隔；真实复现原版快速请求第三次限流，加间隔后 8 个楼层均成功。
- CLE 复用 CAS 后运行学校原版 EMAP 初始化，读取学校提供的本人身份。真实验证：纯 HTTP 为 403；浏览器初始化后，相同 Cookie 的原生 HTTP 查询返回 200/0。
- 书院场地补齐官方 CAS 票据与 `GetUserProfile` 独立令牌兑换；真实读取 35 个场地。票据即取即用，不保存，不重发已消费票据。
- 交换项目复用并自动续接 WS 会话；真实查询返回 24 个项目。
- 校园卡统一登录提示，删除重复“未登录”；学习页与其他带登录入口的页面同步去重。
- 校历参考学校 2026 年原版 PDF：周次、日期、期中/期末考试周、放假/补课及原版活动和教学安排；提供原版 PDF 原生阅读入口。
- 教师目录增加院系筛选。
- 修读进度仅查询“学校总要求”，删除其余损坏接口及栏目。培养方案从教学工作部 2024–2026 级官方文件按需读取，以一张缩略图进入 PDF 阅读；按 TIS 真实入学年级及专业选择，通识通修/通识与学科基础部学生展示整本。PDF 不随安装包打包。
- 首页底部天气默认完整展开，删去重复标题、来源与读取时间；顶部温度和天气图标可跳转到完整天气。

真实凭据及个人资料只在本机临时内存会话中使用，不进入代码、测试样本、截图或云端构建；未执行真实预约、取消、打印、作业提交或支付。

官方资料：[学校校历](https://www.sustech.edu.cn/zh/academic-calendar.html)、[培养方案目录](https://tao.sustech.edu.cn/xueshengfuwu/pyfa/)。

最终测试、截图和安装包核验在发布前补充。
