# SUSTechMobile 0.11.0 / build 16

- 打印网络诊断改用实际 API，不再因入口网页 HTTP 200 就显示整项“可达”。区分拒绝访问、未登录、异常内容和网络错误；公共公钥 API 成功时明确标为“公共接口可访问；校内打印未验证”，不代表校内设备可用。
- 核对打印原站 `printDoc.js`、`scanDoc.js` 和 `footprint.js`：打印/扫描列表成功响应中的显式 `result:null` 按原站显示空列表；缺失字段、未知对象、标量、错误行仍报错。站点/用量仍严格要求数组。补打印请求头与校外拒绝/非 JSON 错误分类；删除残留更新时间。
- 培养方案区域增加内边距，避免列表圆角遮挡文字；专业与全校阅读按钮改为同一个阅读器的互斥选择，一次只显示一个文档。
- IC 日历改为全天 00:00–24:00，自动定位到当天当前时段或其他日期的 08:00；可约时段显示绿色加号，点击进入预约表单。解析 `24:00`、秒格式和明确 `openLimit:0` 的无时段限制规则，结合接口提供的提前时间限制判断可选。支持查看过去 30 天。
- 不再丢弃 IC 接口中带 128 已结束标志的时间记录；本页面刷新时保留之前已读到的过去占用。真实接口本次未返回更早已结束的预约，应用无法补出学校不提供的历史，也不将缺失历史伪装成完整记录。
- “办事”最上方新增“请假”和“学生活动”。两者沿用已保存的 CAS 账号密码及业务 Cookie 自动续接，经学校 EMAP 初始化后读取原生列表，支持分页和下拉刷新。
- 请假原生展示本人记录、起止日期、类型、天数、事由与详情；申请按钮打开已登录的学校完整表单，沿用学校对受影响课程、累计请假天数、审批路径和附件的校验。App 只自动打开空白申请表，不替用户填写或提交。
- 学生活动原生展示标题、时间、地点、类别、举办单位和介绍。核对原站必需的 `TJ1=99&TJ2=99` 筛选参数，本次真实列表共 66 条；未实现或触发活动报名。
- 旧请假页面对官方静态资源的 HTTP 链接仅升级为 HTTPS；未放开 ATS 或降低 Cookie 安全要求。请假链接使用固定入口，不保存用户粘贴 URL 中的临时授权参数。

本机已用账号持有人授权的临时内存会话核对请假列表、本人详情、学生活动分页、IC 规则和打印公共 API。没有提交请假、预约、打印任务或活动报名；没有尝试此前被拒绝的打印密码。真实凭据、Cookie 和个人响应不进入代码、截图或云端构建。
