# 0.10.0 真实接口与会话续接核对

账号持有人已授权本机只读核对。认证凭据、Cookie、令牌和个人响应仅用于临时内存会话，测试完成后已清除；不上传仓库、云端构建或截图。未执行真实预约、取消、打印提交、BB 提交或支付。

| 业务 | 本机真实结果 | 本版处理 |
| --- | --- | --- |
| TIS | 本人身份及专业、院系、入学年级接口成功 | 业务 Cookie 失效自动经 CAS 续接；CAS 过期时遵循已选的记住密码设置 |
| IC | 26 个房间、8 个楼层；快速连续调用第三次触发限流，间隔 1.1 秒后全部 8 组成功 | 合并认证请求；楼层请求间隔；登录失效续接，限流不当作密码失效 |
| CLE | 仅 CAS 登录后接口返回 403；学校 EMAP 页面初始化后，相同 Cookie 的原生 HTTP 返回 200/code 0，本人预约查询成功 | 隐藏网页执行学校所需初始化，业务内容原生显示 |
| 书院 | 即取即用 CAS 票据兑换独立令牌后读取 35 个场地 | 失效后重新兑换，不重用已消费票据 |
| 交换项目 | WS 会话后列表返回 24 个项目 | WS 会话失效自动续接，图片仍只在临时内存加载 |
| 校园卡 | 不带旧 Cookie 返回 302，经 CAS 重新交换后账户与账单 HTML 均返回 200 | 失效自动续接，去掉重复登录提示 |
| Blackboard | 本人接口返回 200 | 原生查询、课件下载及必要网页续接；写入不自动重发 |
| 打印 | CAS 成功不建立打印 API 会话；平台独立密码认证被拒绝一次后停止尝试 | 新增独立打印账号设置；用户提供有效打印密码并选择记住后支持续接。有效打印密码登录成功尚未验收 |
| 修读进度 | 学校总要求接口成功；其余已知损坏接口已停用 | 保留总要求，按 TIS 入学年级与专业展示官方培养方案入口 |
| 培养方案 | 官方 2025 文件 419 页，提纲可以定位对应专业 | 2024–2026 官方文件按需加载，未分流学生展示整本；不随 IPA 打包 |
| 空教室 | 上一轮有效身份下旧目录接口仍返回空体 | 本版没有声称恢复学校损坏接口；不把缺失数据当空闲 |
| 课程评价/教师 | 小数字符串指标回归测试；公开教师快照 994 人、52 院系 | 总分两位小数、四维小分正确解析；支持院系筛选 |

所有已接入学校 Cookie 的原生客户端使用统一恢复回调。安全查询最多重读一次；上传、提交、取消、删除、付款不自动重发。内嵌学校网页到达 CAS 登录时可尝试续接一次，成功后以 GET 回到入口。验证码、独立 OAuth 和没有记住密码时仍可能需要本人操作。

模拟器截图使用虚构示例资料和公开资料，只证明布局；不代表持有人的 iPhone 已完成登录续接或业务写入验收。打印、支付、预约提交、BB 提交和实际帧率仍需对应设备验收。
