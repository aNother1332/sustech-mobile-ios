# 需求记录与阶段计划

记录日期：2026-10-24。状态：用户已同意开始开发，以下是已确认范围与工程默认值。

## 已确认

- 面向本人及少量同学，非商业、非学校官方，不以公开 App Store 上架为第一阶段条件。
- 产品只面向 iPhone 和 iPad，不做 macOS 应用。用户同时有两类真机。
- 当前没有 Mac、没有付费 Apple 开发者账号；已确认采用 GitHub 云端 macOS 编译、Windows AltStore 侧载的个人试用路线。
- Windows 上推进设计与实现，构建、签名、真机安装方案需要后续落实。
- 最终尽量完整对齐 Android；允许原生与官方网页结合，不要求所有事务都原生完成。
- 客户端直连学校，凭据留本机，低成本维护，不托管学生密码到聚合服务器。
- 接受 iOS 后台限制，不承诺新成绩、新公告即时通知。
- 分批试用，第一批优先登录/会话、课表/考试、BB 课程/待办和官方服务入口。
- 尽早验证打印上传、CLE WebView 会话、充值跳转，不在技术验证前承诺可用。
- 新增优先候选：统一待办、课件与离线阅读、系统日历、排课工作台、空教室、分享打印。
- 学业进度、预约增强、变化检测为后续候选。
- 同意优先考虑 BB 文件提交；手动选退课后续候选，投点暂缓，不做自动抢课。

## 工程默认值，可随实测调整

- SwiftUI + Foundation / WebKit，独立 CampusCore Swift Package，无第三方 iOS 依赖。
- 最低 iOS / iPadOS 17；Xcode 26+；Swift 6 语言模式。
- 工作名“南科 · 日常”，临时 bundle ID `cn.sustech.community.daily`。
- 第一批不读密码：由学校网页处理登录，应用复用本机 WebKit cookie。
- 网页会话由系统保存，原生数据暂在内存；重启后手动同步验证会话有效性。
- 真实模式默认空数据；演示模式可选，切换后清空显示数据，防止混淆。
- 使用原生动态字体、系统色和自适应导航；iPad 与 iPhone 均需要实机验收。

## 阶段 0：当前源码起点

交付：原生页面、可选演示模式、学校网页入口、TIS/BB 只读适配代码、测试与构建工程。
退出条件：核心测试与模拟器构建在 Mac 通过，修复所有 Swift / SDK 兼容问题。
当前尚未满足此退出条件，不能对外宣称已交付可用 App。

## 阶段 1：首批真实试用

1. 确定可用的 macOS 构建环境及设备安装方式。
2. iPhone、iPad 实测学校交互登录与 cookie 复用；覆盖验证码、过期与重启。
3. 对照学校网页核对当前学期/周、周课表、考试、BB 课程及截止日期。
4. 接入可靠的 BB 提交状态契约，保留 unknown / partial，才将相应项目称为“待交”。
5. 验证打印上传、CLE 会话和微信充值路径，记录网络要求和失败边界。
6. 增加受保护的离线缓存与更新时间，再按需求接入本地提醒。

## 阶段 2：继续对齐 Android

| 模块 | 对齐目标 |
| --- | --- |
| 教务 | 学期课表、成绩/GPA、考试、课程详情；遵循官方记录 |
| BB | 课程、结构化任务、提交状态、公告，部分失败可见 |
| 校园卡 | 余额、账单、校园码/身份码，充值交由官方支付环境 |
| 打印 | 文件上传、参数、队列/删除、扫描、站点、用量 |
| 图书馆 | 实时人数、检索、馆藏、借阅、续借 |
| IC 研讨间 | 列表、空闲、预约、我的预约、取消 |
| 场馆 | 场馆/我的预约；允许官方页面完成预约与取消 |
| CLE | 我的预约、配额，官方页面预约 |
| 国际交流 | 列表、筛选、详情与官方申请页 |
| 交通 | 站点、方向、车辆、预计到站，保留来源与时效 |
| 校园信息 | 课程评价、教师目录、天气/AQI、Wi-Fi 官方入口 |
| 系统集成 | 下一课等小组件、缓存与本地提醒，受后台能力约束 |

目前服务目录只提供其中一部分官方网页入口，不代表上述原生能力已完成。

## 阶段 3：新增能力

已认可的六项优先候选按可独立验收的批次实现，不承诺同一版本全部发布。
BB 文件提交仅在支持的作业类型及真实回执验证后启用；不得从截止日期推断提交状态。
选退课等写操作另行验证用户权限、选课阶段、错误回读和防止重复提交的行为。

## 尚待安排的外部条件

- 云构建使用私有 GitHub 仓库的手动工作流；Windows 免费个人签名仍需用户本人安装工具并认证，不自动购买开发者账号或增加构建预算。
- 用户可使用自己的校园账号；校内与校外网络的覆盖需分别实测。
- iPhone / iPad 型号、系统版本尚未提供，最低系统版本只是工程默认。
- 上游接口更新和真实写操作需持续维护，没有学校官方 SDK 或可用性承诺。
