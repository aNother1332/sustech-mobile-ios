# SUSTechMobile 0.9.0 / build 13

本版重做个人资料、设置、NCES、交换项目和 IC 讨论间日历，并统一业务页的字体、按钮、卡片与错误提示。

- “我的”以真实个人资料为主体，合并 TIS 专业、院系资料；保留我的预约、下载文件和日程提醒，账号、缓存、更新及来源移入设置。
- 删除课表、考试等页的学期/登录状态框、连接成功标识、读取时间及手动刷新按钮；保留下拉刷新。失败显示一行短错误，不弹窗；仅确认身份过期时出现红色登录操作，网络失败保留缓存。
- 正式版无演示模式切换、永久备用网页登录入口；学校确实要求交互验证时才在登录过程中打开验证页。
- IC 使用房间 × 半小时时间网格，按日期读取实际开放时间与预约占用。点击可用未来时段填写预约；缺失/异常日程保持不可选。预约提交/取消仍需最后一次确认。
- NCES 改为蓝白卡片，显示原站 10 分总评分、难度/作业/给分/收获四维数据，按真实分页加载课程与评价。
- 交换项目修复 HTML 数字实体与嵌套实体显示，提供原生详情；真实图片只为可见内容按需加载，不使用磁盘缓存，离页取消请求并释放。
- 校园卡、打印、书院场地、教师、校园码等使用相应的业务页头与紧凑内容布局，继续使用苹果系统字体。

体育未取得可验证的原生登录或企业微信对应页直达，按用户要求移除原生体育、复制流程和无效入口。

本机只读核对确认：TIS学生资料接口包含专业；IC普通日历按日期与楼层返回开放时间和占用；交换列表有真实图片字段，文字含HTML数字实体。真实个人资料不用于测试样本或截图。

高刷新率采用iPhone所需配置和当前窗口的显示能力检测，保留系统自适应调度，不承诺所有电源与温度条件下恒定120fps。

**空教室尚未恢复真实查询**：有效教务登录与学期查询正常，但原目录接口多组参数均返回 HTTP 200、零字节内容。界面自动加载、下拉刷新、错误与未知占用处理已调整，不将查询失败当成空闲；尚未找到可验证的替代目录来源。

未执行真实预约、取消、打印提交、BB 提交或付款。体育入口按上述约定移除；原生充值下单与自定义金额仍未验证，未开放付款操作。

本机业务证据、官方高刷新率资料及验证边界见 [业务核对记录](BUSINESS_VERIFICATION_0_9.md)。构建、截图和安装包核验结果见 GitHub Release 的交付记录。
