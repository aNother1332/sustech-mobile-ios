# 设备验收

## 0.6.1 本人设备待验收

- [ ] 校内实机国内底图：至少三处地标核对站点、线路和车辆；若使用海外底图，关闭地图对齐开关再比对。
- [ ] 不登录打开打印站点，出现设备名称及状态；切换扫描/用量仍需要本人登录。
- [ ] 教务登录后显示已登录；断网显示暂无法验证，可明确重新检测或手动登录。
- [ ] 默认不开启保存；本人勾选后登录，彻底退出重启，仍有效时复用 Cookie，失效时自动补登。
- [ ] 关闭记住开关立即删除密码；“我的”删除凭据保留 Cookie；清除会话同时删除凭据。
- [ ] 学校要求验证码或拒绝密码时暂停自动尝试，手动处理后再恢复；不用反复输错密码做测试。
- [ ] 体育授权按钮打开网址；企业微信环境限制通过系统分享处理，无需跨设备扫码。
- [ ] 书院场地网页登录后原生目录/日程和官方页面一致；最终预约仍在官方页提交。

## 0.6 首页、教师与地图

1. 未登录时打开首页，核对学校校历中的当前教学周；切换本科/研究生校历，并检查日期与教学周一致。
2. 教师目录选择一位教师，核对邮箱和办公室与官方页面；尝试复制、邮件、下拉刷新，再离线重新打开。
   对未提供办公室、失效个人主页、脚本加载页面，确认缺失提示和官方链接，不接受推测地址。
3. 校车地图核对校园底图、线路轨迹与站点对齐；选择线路、点击车辆与站点，检查真实方向和下一站。
4. 比较车辆上报时间与接口读取时间；断网/上游停止上报后应保留旧时间、标灰，不应伪造新位置。
5. 切后台再回来、地图/站点切换、暂停服务车辆开关、网络恢复后重试；停留地图时应约每10秒更新。
6. iPhone/iPad、浅色/深色、地图旋转缩放和系统大字号；示例车位置与示例联系方式不得作为真实数据。
