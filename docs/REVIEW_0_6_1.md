# 0.6.1 修改核对

| 用户要求 | 本轮实现 | 验证边界 |
| --- | --- | --- |
| 校车向西北偏移 | WGS-84 → GCJ-02 只作用于国内底图展示；线路、站点、车辆、中心一致；保留原坐标模式 | 既定数学基准通过，校内实际地标仍需实机比对 |
| 体育授权不扫码 | 新增外部 HTTPS 授权按钮，二维码移入备用折叠区，保留企业微信分享 | 企业微信授权环境与回调导入仍需用户实测，不承诺外部浏览器自动取得令牌 |
| 其他场馆原生 | 书院目录、详情、当日安排为原生；独立 booking 令牌复用 | 最终预约提交仍为官方网页，不能宣称完整原生预约已完成 |
| 打印站点无法显示 | 公开查询绕开 CAS，空结果/失败提示，下拉刷新 | 公开接口实测 26 个有名称站点；设备状态由学校上报 |
| 教务登录状态不明 | 改用课表同源受保护学期接口验证；所有状态可展开登录；检测中不可重复检测，但可打开登录 | 真实账号状态与断网行为待实机；不能把网络失败当密码失效 |
| 记住账号密码自动登录 | 主动选择、登录后存本机钥匙串；前台先校验 Cookie，再对确认失效补登；五分钟冷却，拒绝/挑战/限流暂停；关闭时删除，失败提示 | 未使用用户真实密码进行测试，钥匙串和自动登录需本人设备验证 |

凭据不进入 UserDefaults、缓存文件、日志或 CI。UserDefaults 仅保存自动登录暂停标记。钥匙串 WhenUnlockedThisDeviceOnly，无跨设备同步。切换账户时停止旧账号自动登录；退出清除凭据。表单关闭保存开关即时删除，不依赖再次提交。

本轮不执行真实预约、打印上传或支付；测试回包使用虚构令牌及示例数据。
