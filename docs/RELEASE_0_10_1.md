# SUSTechMobile 0.10.1 / build 15

- 首页顶部温度统一为 `℃`。
- 自动续接使用单独合并的 CAS 认证任务，直接使用已记住的账号密码恢复学校登录。不再调用完整的手动登录流程，不改变账号版本号、不销毁正在加载的业务页面；恢复后继续原来的查询。退出或切换账号会取消旧认证任务。错误密码、验证码等仍停止静默重试。
- 教务登录检测从“当前学期”改为真实 `/user/me` 身份接口。本机核对发现学期接口未登录时也会返回数据，不能作为登录有效依据。
- IC 真实共享 CAS 交换后，`userInfo` 返回 code 0 且有有效账号。未执行预约或取消。CLE 等 CAS 业务共用修正后的恢复流程，设备上的全部交互仍需实测。
- 培养方案年级选择由表单 Picker 改为独立菜单，明确阅读卡片与菜单各自点击区域，避免阅读卡片点击被年级选择器接管。
- 空教室旧目录在真实有效身份下仍返回 HTTP 200 空响应。增加全校课表替代查询：本次真实读取 1,514 条完整课程、2,681 个时段、238 个教学地点，解析全周、单双周和节次。页面显示“有课／无课”，并标明“课程占用 · 临时借用未知”。该来源不覆盖临时借用，不能将“无课”当作场地可用保证；目录恢复时继续用原来的实时占用查询。

真实账号只在本机内存中做只读核对；凭据、Cookie、身份数据不进入仓库、云端构建或截图。自动化测试使用虚构样例，截图仅用于布局核对。
