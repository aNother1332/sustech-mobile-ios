# 0.2.0：前三批功能实现与验收

应用名称：SUSTechMobile，版本 0.2.0（构建 3）；图标使用官方校徽中央火炬，深青底，无外围文字与圆环。

本版范围：原生学校登录；全学期课表/离线/成绩；BB 任务、公告、课件与离线文件。
学校真实账号接口尚需用户在设备验收。测试使用虚构数据，不含真实校园凭据。

## 使用路径

1. 我的 → 切换到“学校服务” → 登录学校账号，输入账号密码。
2. 教务和 Blackboard 分别验证；出现验证码或表单变化时使用完整学校网页备用入口。
3. 学习 → 课表：同步全学期课表与考试，切换教学周。学校节次时刻读取成功后显示。
4. 学习 → 成绩：单独同步成绩，按学期筛选。GPA 为明确标记的原始记录试算，未合并重修/替代，及格制和未知等级不猜测，不作为官方总 GPA。
5. 学习 → BB：同步课程列表，进入单个课程，读取任务及公告。首页仅汇总已同步课程，不能理解为已检查全部历史课程。
6. 课程 → 课件：按目录浏览，读取附件，选择下载。下载完成后可离线预览或分享至“文件”；主学习页的离线文件入口可查看与删除下载。

## 认证与本机数据

- 密码仅存在于本次原生登录任务中，输入框提交时清空，不保存到普通配置、日志或服务器。
- CAS GET 解析 execution，POST 只发给 CAS；跳转逐一限制 HTTPS、CAS 和当前服务主机，后续使用 GET。
- 发现活跃验证码输入框时不提交密码，交由官方交互流程；不实现绕过挑战或自动重试密码。
- 新登录首先清除旧会话和缓存。每项服务读取成功才显示对应连接结果。
- 课表、成绩、BB 课程详情、课件目录及下载元数据在 Application Support 受文件保护保存，并排除系统备份。不会把密码或网页 cookie 写入此 JSON 缓存。
- 退出/切换账号清除本机缓存与下载文件；演示模式不会写入真实缓存。
- 从教务/BB 学校网页入口进入时先清除当前缓存，防止用户在网页中切换身份后混用数据。同时清除旧网页会话，随后由学校页面重新建立身份，完成后手动同步。
- 重启后缓存显示“尚未验证当前会话”和最近同步时间；有缓存不等于仍登录或数据实时。

## 功能边界

- 全学期周次按上游固定版本的 ZC 位图解释：索引 i 对应第 i 周，索引零为填充。没有可靠周次的条目单列，不自动排到每周。全学期读取失败时可退回当前周，明确显示错误。
- 不自行推算校历、调休和实际日期；本版没有日历导出、通知、小组件。
- 成绩读取有分页和重复页/不完整响应检查。每条学校成绩原文保留；本地 GPA 试算与官方结论区分。
- BB 提交状态校验所属账号；404、无权限、未知状态、未核验任务类型保留未知。草稿与已提交分开；无截止日期任务保留。仅逐课程按需读取，降低请求突发。
- 课程附件支持 REST 附件、同源 BB 文件和正文中的 bbcswebdav 链接。外站文件保留官方入口，不转发学校会话。
- 下载使用临时文件和原子元数据更新，同源跳转逐次检查；拒绝 HTML/JSON 错误响应和零字节文件，完成后检查单文件 200 MB 上限。不是所有外链/特殊格式都支持。
- 课程正文和公告显示安全的纯文本，复杂排版与完整外链使用官方网页。
- 本版不新增作业提交、选退课、打印、预约或支付操作。

## 必须真机核对的项目

- 账号正常登录、错误密码、验证码、网络错误与过期会话；CAS 成功不冒充全部服务成功。
- 与学校网页逐项核对课表周次、节次时间、考试、分页成绩。
- BB 本人已交、草稿、未交与未知至少各覆盖实际可用样本；无权限课程应显示部分失败。
- 下载一个本人有权访问的普通 PDF，离线预览、分享、删除；检查登录页不被存为课件。
- 重启后离线查看；切换账号、演示模式和清除会话后无旧请求数据回流。
- iPhone 与 iPad 横竖屏和分屏；修正后的学校网页是否能完整显示。

## 自动验证

新增 CAS 表单/挑战、跳转白名单、实际 HTTP 登录流程、成绩多页读取、位图、GPA、BB 状态所属账号与缓存模型往返测试。云工作流执行 Swift 测试、模拟器构建、arm64 真机编译和 IPA 打包检查。构建结果另行记录，不将构建通过代替以上真机验收。
