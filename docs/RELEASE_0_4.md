# 0.4.0（构建 7）实施与独立验证记录

## 本轮范围

- 图书馆馆藏搜索、馆藏位置、收藏、人数；借阅连接、在借记录、续借确认和回读。
- NCES 社区课程评价搜索、分页、详情和本机收藏；学校候选教学班只读查询/收藏/导入、本地三套排课方案、周次/节次冲突和学分比较；教务官方修读进度读取。
- 统一日程、课程日期人工校历锚点、考试/BB任务/IC/CLE/体育/借阅到期汇总；个人事项；系统日历添加/更新和本地提醒。折叠 BB 课程时移除相关待发本地提醒。
- 课件 PDF 到打印参数；打印站点、扫描元数据、用量分页；独立系统分享 PDF 扩展及主 App 共享收件箱。
- BB Original 个人单文件作业：只读预检、最终确认、新表单/nonce、一次提交、唯一新增 attempt/文件名回读；本机持久待确认记录和只读回查。
- 学校会话自动检测、按服务显示有效/失效/未知/网络不可验证；有效时隐藏登录按钮；前台恢复和网页登录返回后检测；同账号重新认证保留其他服务会话，换号/主动退出才清理；关键查询下拉刷新。
- 紧凑卡片、缩减留白、说明折叠，增加首页/学习快捷入口。

## 未完成的充值闭环

只读协议审计没有证实外部企业微信到 WKWebView 的授权交接、当前启用的充值下单分支/响应和权威单笔到账查询。已实现严格同源授权读取、Keychain 保留、身份只读校验、金额准备；真实下单明确关闭，继续保留外部充值入口。没有以试探 POST 验证收费接口，也不将返回网址当作支付成功。详见 WRITE_PROTOCOL_AUDIT_0_4.md。

## 两种安装包

普通 SUSTechMobile-unsigned.ipa 排除 PlugIns，便于继续使用现有签名工具。SUSTechMobile-with-share-unsigned.ipa 包含校园打印分享扩展，需要主 App/扩展正确签名及同一 App Groups 容器。免费账号、iLoader 是否保留对应授权尚待本人设备验证，不能声称分享扩展已在真机可用。共享容器只放用户主动分享的 PDF，不保存密码/Cookie；扩展不自动上传、不用未公开方式唤起主 App。

## 业务边界

排课可从学校候选教学班导入或手工维护，不执行学校选课。候选查询采用上游 bxxk 选课范围；范围未开放、研究生培养类型或未知时段需学校页面核对。主课/实验组合不会自动判定已满足选课规则。修读进度按学校字段展示，类别不合计为毕业资格。扫描暂提供元数据，未猜测下载地址。课程日期需本人核对第一教学周周一，调休不自动推断。日历由用户管理，折叠课程不会自动删除已导出系统事件。提醒基于最近一次同步，不承诺后台实时更新。

## 公开只读接口探测

2026-10-25，Windows Python：NCES `/api/v1/search` 返回 HTTP 200，包含 courses/reviews/teachers，courses.items 为数组，与客户端契约一致。Primo 公共馆藏查询在本机 OpenSSL 网络栈报 `UNSAFE_LEGACY_RENEGOTIATION_DISABLED`，没有降低 TLS 校验；这不是 iOS URLSession/WKWebView 的验收结果，图书馆直连兼容性需本人设备实测。
