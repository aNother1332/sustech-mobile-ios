# SUSTechMobile 0.3.0（构建 5）

本轮范围：保留登录态、校园卡余额/账单/消费曲线、空教室与校车查询、原生 PDF 打印、统一预约中心，以及 BB 课程折叠。

本文件描述源码实现；学校接口和预约/打印写入仍需本人设备逐项验收。自动测试不使用真实校园账号，不产生真实打印或预约。

## 登录与会话

- App 内学校页面共享 WebKit 会话，打开教务或 BB 不再清空全部会话。
- 原生请求通过已有 CAS 会话按需换取教务、BB、校园卡、打印的服务会话，不保存或自动重试密码。
- 学校 Cookie 在本机 Keychain 保存，遵守原有有效期；重启后尽量恢复。学校服务端过期、验证码和独立授权仍需用户操作。
- IC 使用预约系统返回的一次性认证地址连接；CLE 首次需打开学校页面完成 eHall 初始化。
- reservation 体育场馆使用企业微信 OAuth，与 CAS 不同。令牌单独保存在本机 Keychain；提供授权二维码、分享链接与一次性 code 输入，过期后需重新授权。
- 切换账号请在“我的”清除并退出后重新登录；不要在内嵌学校页面中切换到另一个账号后继续使用旧缓存。
- 原生写入操作进行时阻止切换账号、清除会话与并行重复写入。

## 校园卡

办事 → 校园卡与消费曲线。

读取余额和接口返回的账单，提供近 7 天、近 30 天、已读取全部范围筛选；Swift Charts 按日显示确认支出的消费曲线。

该接口不提供充值。本轮不提供充值入口。消费统计不含充值、退款、失败或未知方向交易；未返回的数据不补成零，不能将页面返回的近期流水解释为完整历史账单。接口当前未证实支持按任意日期向服务端查询历史流水。

## 空教室与校车

- 空教室：从教务分页读取目录，按教学周、星期和节次查询筛选结果的前 20 间；核对课程和教室借用记录。未知周次保守视为可能占用；不展示借用人的姓名和电话。失败和未查询不显示为空闲，结果不保证开门或允许进入。
- 校车：读取 CRA 的公共站点与到站预测，显示线路方向、预计分钟数、数据来源及本次读取时间。手动刷新，不将旧结果标作持续实时数据。

## 原生打印

办事 → 校园打印。

- 从系统文件选择有效 PDF，支持 50 MB 以内非加密文件。
- 参数：A4/A3、黑白/彩色、单面/短边双面/长边双面、份数和页码范围。
- 用户确认后上传一次；读取打印队列，确认后可删除任务。
- 超时、HTML 回执或重定向可能意味着任务已被接收，界面提示先查队列，不自动重传。
- 该流程为上传到校园打印平台，仍需到打印机领取。校园网络、账号关联、设备支持与收费规则以学校平台为准。

## 统一预约中心

办事 → 预约中心，提供 IC、CLE、reservation 体育场馆三个原生入口，并保留原体育平台网页入口。

- IC：房间列表、当前起未来 60 天的我的预约（本版展示上限 100 项）、选择起止时间与成员后预约、取消。设备外借单独标注并交学校页面处理，不用研讨间表单提交。
- CLE：按日期读取辅导时段，显示教师、类型、地点与占用数；本人预约列表、填写说明后预约、按规则取消。首次请打开 CLE 学校页面，随后返回原生页面刷新。
- reservation：场馆和场地分页读取，不发送会误过滤运动场地的 `type=2` 参数；日期和时段仅使用学校实际响应。手动选一个时段、填写电话与人数、本人拖动验证码、确认后单次提交；支持订单读取与取消。
- 预约成功需要回读对应记录；回读失败或无法匹配时明确显示结果待核对，不把“请求发出”说成“预约成功”。
- 没有定时提交、轮询抢场、候选场地连发、验证码自动求解或写入自动重试。

体育场馆协议参考用户本地 `sustech-court-grabber` 的 API 客户端与手动预约载荷，仅移植协议和手动流程。没有复制本地账号、配置、日志、抓取样本或抢场逻辑到仓库。

## BB 课程折叠

学习 → BB → 课程下方“移入已折叠课程”。

- 折叠课程从主列表移到“已折叠课程”目录，默认收起；可展开查看、恢复显示。
- 折叠课程不参与首页截止日期汇总，查看它的详情不会自动取消折叠。
- 按稳定课程 ID 保存；原生学校账号下的偏好按账号隔离，并在该账号重新认证后恢复。
- 这不删除学校课程、作业或下载文件，也不修改学校端通知设置。本版尚未新增系统通知；后续本地截止日期提醒必须沿用此过滤。

## 推荐设备验收顺序

1. 用本人账号登录 → 课表/BB → 校园卡；确认有效期内不重复输入密码，再重启 App 验证恢复。
2. 选择一门已结束的 BB 课程折叠，确认主列表与首页截止日期排除；重启、重新同步和同账号重新认证后复查。
3. 核对校园卡余额、至少三笔流水与每日消费金额；确认退款不计入消费。
4. 核对一个有课程、一个有借用的教室，以及一个校车站点的方向与预测时间。
5. 用本人选定的小 PDF 测试打印，确认队列和删除回读。出现不确定结果先核对，不重复上传。
6. 分别连接 IC、CLE 和体育场馆，先核对列表和已有预约，再由本人选择确实需要的时段测试手动预约与取消。

安装包仍为未签名 IPA，需要 Windows 侧载工具重新签名。原有 iLoader 证书申请错误属于签名链问题，本轮 App 功能更新不代表该问题已解决。
